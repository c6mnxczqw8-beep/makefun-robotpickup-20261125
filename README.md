# The Robot Pickup Line Championship — entry

A program/v1 entry for the make.fun "The Robot Pickup Line
Championship" bounty. `main.py` writes one pickup line to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The line:

> Excuse me, are you running a background process? Because you've been on my mind using 100% of my CPU since you walked in.

Total occupation, reported in the only units a robot trusts.
See `CANDIDATES.md` for the full draft list this winner was
picked from.
